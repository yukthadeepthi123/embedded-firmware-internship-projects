# Embedded Communication Protocols

## Overview

This section contains hands-on embedded systems projects demonstrating communication protocols using Arduino, ESP32, and peripheral devices.

## Protocols Covered

### 1. UART – Universal Asynchronous Receiver/Transmitter
- UART Serial Data Monitor
- UART Command-Based LED Controller

### 2. I2C – Inter-Integrated Circuit
- I2C Device Scanner
- I2C MPU6050 Sensor Reader

### 3. SPI – Serial Peripheral Interface
- SPI Data Transfer Test
- SPI Peripheral Data Reader (74HC165)

## Tools and Technologies

- Embedded C / Arduino C++
- Arduino Uno
- ESP32
- Arduino IDE
- Wokwi Simulator
- UART, I2C and SPI

## Learning Objectives

- Understand serial communication protocols.
- Configure and use UART communication.
- Scan and communicate with I2C devices.
- Perform SPI data transfers.
- Interface microcontrollers with external peripherals and sensors.
